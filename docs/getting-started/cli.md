# Project CLI

`astra2d` is an optional Node.js command-line tool (published on npm as `astra2d-cli`) that scaffolds LÖVE projects using Astra 2D and creates scene modules. You can also assemble the same files by hand in [Your First Project](/getting-started/first-project).

## Requirements and installation

- **Node.js 20 or newer** to run the CLI.
- **LÖVE 11.5** to run the generated game; the CLI does not install it.

```sh
npm install -g astra2d-cli
astra2d --help
```

For local development, install the dependencies from the repository's `cli/` directory, run `npm run build`, and use `npm link` or `node bin/astra2d.js`.

## Create a project

```sh
astra2d init my-game
cd my-game
love .
```

`astra2d init <project-name> [ruta]` creates `<ruta>/<project-name>`, or uses `.` when `ruta` is omitted. Use `.` as the project name to initialize the current directory in place:

```sh
astra2d init mi-juego ../proyectos
astra2d init .
astra2d init . ../proyectos
```

The command downloads `engine/` from the latest GitHub release or tag of `Damet24/Astra2D`. If the download fails, it warns and uses the engine copy bundled with the npm package, so it also works offline. Set `GITHUB_TOKEN` if you need a higher API rate limit or access to a private repository. It refuses to write if the destination already exists, or if `engine/`, `main.lua`, or `game/` already exist when initializing in place.

The generated project has this layout:

```text
my-game/
  engine/                 # engine source, including engine/lib/
  main.lua
  game/
    config/
      collisionLayer.lua  # conventional collision category IDs
      inputMaps.lua       # named actions
      resourceDefinitions.lua
    scenes/
      main.lua            # initial scene
```

`main.lua` requires `game.config.resourceDefinitions` and `game.config.inputMaps`, and sets `initialScene = "main"`. The initial scene prints a timer and exits on Enter or gamepad Start. This is a minimal starting point: it has no assets, cameras, or physics, and does not replace the example game in [Installation](/getting-started/installation).

## Create scenes

```sh
astra2d scene:create Level1
astra2d s:c Level1 game/scenes
```

`scene:create` (alias `s:c`) copies a scene template and replaces the placeholder with the name you provide. By default it writes `game/scenes/Level1.lua`, which resolves to the Lua module `game.scenes.Level1`; the optional second argument chooses another directory. The name must be a valid Lua identifier, and existing files are never overwritten. The template includes `onLoad`, `onEnter`, `onExit`, `onDestroy`, `update`, and `draw`.

## Notes

- The CLI version is independent of the engine version. Check the [npm package](https://www.npmjs.com/package/astra2d-cli) for the current release.
- The bundled engine copy is regenerated by `npm run build` (and automatically by `prepack` before publishing).
- The CLI does not add assets, install LÖVE, or run the game for you.
