# Guides

These tutorials build on [Your First Project](/getting-started/first-project). Each focuses on a practical task and explains the required setup.

- [Create and manage scenes](./scenes): scene lifecycle, deferred transitions, and overlays.
- [Load and release resources](./resources): definitions, consumers, and cleanup.
- [Configure controls](./input): action bindings and frame-based input.
- [Play music and sound effects](./audio): playback, volume, and resource ownership.
- [Integrate Tiled maps](./tiled): export, render, and create wall colliders.
- [Configure cameras and viewport](./cameras): world views and coordinate conversion.
- [Work with entities and systems](./ecs): ECS, physics, and system order.

For concise method signatures and return values, see the [API reference](/api/). To see the components working together, try the [example project](/examples/).
